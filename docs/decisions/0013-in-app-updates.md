# 0013 — In-app updates from GitHub Releases

Date: 2026-09-15 · Status: accepted

## Context

Every release so far meant: download the `.dmg`, quit the app, drag over the old copy, reopen. Users also
launched the app from the mounted `.dmg` by mistake (App Translocation, no persistent grants), and a core
process from the previous install kept serving the old API under the new UI (fixed alongside this ADR by a
bundle-version handshake in `core.rs::core_is_current`).

## Decision

1. **Tauri updater plugin**, artifacts signed with a minisign key generated by `tauri signer generate`.
   Public key in `tauri.conf.json` (`plugins.updater.pubkey`); private key and password in the repository
   secrets `TAURI_SIGNING_PRIVATE_KEY` / `TAURI_SIGNING_PRIVATE_KEY_PASSWORD` and in the maintainer's
   `~/.brainlogs-signing/`. Losing the key means shipping one manual update with a new public key.
2. **Endpoint:** `https://github.com/ShivankK26/Brainlog/releases/latest/download/latest.json`. The publish
   job writes `latest.json` with `tooling/release/latest-json.mjs` from the collected `.app.tar.gz` /
   `-setup.exe` / `.AppImage` artifacts and their `.sig` files. macOS ships one universal archive under the
   `darwin-universal`, `darwin-aarch64` and `darwin-x86_64` keys.
3. **UI, not Rust, drives it.** `window.__TAURI__.updater.check()` on launch and every 6 h; a sidebar button
   runs `downloadAndInstall()` then `process.relaunch()`. Capability `default.json` grants `updater:default`
   and `process:default` to the local-core origin. Outside the shell, or when the endpoint is unreachable, the
   check fails silently and nothing is shown.
4. The updater relies on ADR 0012: because releases share one signing certificate, the replaced app keeps
   its Accessibility grant.

## Consequences

- Works only when `latest.json` is publicly downloadable, i.e. once the repository is public (GitHub serves
  private release assets only with a token). Until then the button never appears and `install.sh` or the
  `.dmg` remain the upgrade path.
- Local `tauri build` without the secrets produces no updater artifacts; the publish job tolerates a
  platform with no `.sig` by leaving it out of the manifest.
- Downgrades are not offered; the plugin only installs versions greater than the running one.
